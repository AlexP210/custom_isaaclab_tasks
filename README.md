# Custom IsaacLab Environments

This repo hosts custom IsaacLab environments for the [Task-Specialization Through Distillation](https://github.com/AlexP210/tsd) (TSD) project.

Some notable files:
- `source/custom_isaaclab_tasks/custom_isaaclab_tasks/tasks/direct/boxplace/boxplace_env.py`: Implementation of the box-sorting task used for prototyping TSD.
- `source/custom_isaaclab_tasks/custom_isaaclab_tasks/tasks/direct/boxplace/boxplace_env_cfg.py`: Configuration file for the above environment.
